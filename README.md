 ## 𝚆𝚑𝚢?

I am learning JavaScript over 30 days. To be honest, my first instinct was to do what I always do: write some code in a scratch file, test it, and forget it ever existed the moment I closed the tab. A week later, I probably wouldn't remember what I learned on Day 2.

That felt like a waste. The individual code files might not matter much on their own, but the process of figuring things out deserved to be kept somewhere better than a temporary file that gets overwritten the next day. I wanted a way to go back and actually see my progress.

So, I decided to build a library for it instead of just keeping a messy folder.

Every day becomes a book on a digital shelf, complete with a title, custom color, and a set place. When I want to review what Day 7 taught me, I can just pull that specific book off the shelf to look at it. After 30 days, this shelf will be a direct record of the work I put in.

This project isn't a polished tutorial or a commercial product. It is just proof that I stuck with something for 30 days straight and can point to exactly what I built on any given day.


## 𝙷𝚘𝚠?
<img width="870" height="790" alt="Screenshot 2026-07-19 at 20-19-51 Sequence Diagram syntax and features" src="https://github.com/user-attachments/assets/f757b05e-2a75-47d5-9840-5a3be185475c" />

✴︎Each day of practice lives as its own standalone .js file, containing a short note on what I learned.

✴︎The local Node.js + Express server reads those files and builds the bookshelf automatically, so there is no need to manually update or rebuild the page every day.

✴︎Clicking a book loads that day's code and notes directly into the interface, rendered into the .html template.

✴︎Put the book back, and the shelf is exactly as it was — ready for tomorrow's addition.
